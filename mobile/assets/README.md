# Assets Directory

This directory should contain the following files:

- icon.png (1024x1024) - App icon
- adaptive-icon.png (1024x1024) - Adaptive icon for Android
- splash.png (2732x2732) - Splash screen image
- favicon.png (16x16 or 32x32) - Web favicon

For now, these are placeholder files. When building the app, you'll need to provide actual image files.

You can generate placeholder images using tools like:
- https://www.favicon-generator.org/
- https://appicon.co/
- Online icon generators
